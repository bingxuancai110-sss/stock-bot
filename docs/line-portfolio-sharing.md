# LINE 秉軒持股分享

使用者已授權其他人查看其持股圖卡。原先「秉軒的持股」雖有獨立別名，卻把發訊者 user_id 傳進圖卡，因此別人看到自己的空持股。

本次只修正具名分享指令的讀取對象，回覆接收者仍是發訊者。一般「持股」查自己的資料、網頁登入、交易寫入、LINE Reply/Push 邏輯均不變。

分享圖卡沿用配置比例、今日漲跌與經隱藏股數的操作日報；不提供登入憑證、編輯權限、實際股數、持股成本或金額。不改資料庫。

只有一位 ADMIN_USER_ID 時以該管理員為已授權分享的擁有者。多位管理員時必須明確設定 LINE_SHARED_PORTFOLIO_USER_ID 且屬於管理員名單；不任選第一位、不以發訊者當預設、不依可任意修改的顯示名稱尋人。若新增管理員，務必明確設定分享擁有者。

正式站確認有多管理員歧義，因此提供本人於 LINE 一對一對話輸入「公開我的持股」綁定。以既有 shared_data_snapshots 的 line_shared_portfolio_owner 保存，不含登入 token。資料庫原子條件寫入只容許初次綁定或同一帳號重複確認，其他管理員不能覆寫。一般使用者、群組及聊天室不能設定。查詢時仍確認擁有者屬於有效管理員。這項設定沒有新增資料表，回滾後可保留此設定列。

2026-11-11 修正：分享未綁定時，管理員本人在一對一對話仍可用原具名指令讀取自己的圖卡；分享設定讀取失敗也不阻斷這項本人查詢。未設定時其他使用者和群組仍不能使用此退回路徑。已有明確分享擁有者時沿用該擁有者，不重新綁定、不自動公開任何帳號。24 項相關測試通過。此變更只恢復本人讀取，不表示已完成實際 LINE 對話驗收。
