# LINE 秉軒持股公開查詢

使用者已明確授權任何人輸入「秉軒的持股」皆可查看同一份持股圖卡，不需要本人另行啟用。

原本具名指令錯用發訊者的 user_id，朋友會看到自己的空資料；後續分享綁定又把本人擋住。現在查詢對象完全獨立於發訊者，回覆接收者仍為發訊者。一般「持股」查自己的資料，登入和交易權限不變。

擁有者解析順序：既有明確分享綁定；既有分享帳號設定或單一管理員；原本已設定的個人行情擁有者 UID／Google email 精確映射。所有擁有者均須為有效管理員，email 必須唯一，不依顯示名稱或管理員順序猜測。明確設定無效時停止，不任意改選其他帳號。啟動時只記錄解析是否成功，不輸出個資或憑證。

公開內容沿用現有圖卡：配置比例、今日漲跌與已隱藏股數的操作日報。沒有公開實際股數、成本、資產金額、API 金鑰、登入連結或編輯權限。原有「公開我的持股」管理指令保留作為明確綁定入口，但本次已授權帳號不必再輸入。

驗證：28 項相關測試通過，包含本人、一般使用者、另一位管理員均讀取同一擁有者、指令別名、唯一 email、無效設定、一般持股資料隔離及圖卡回歸。正式 LINE 收到圖卡仍需使用者發出查詢確認，不以合成測試宣稱訊息已送達。

部署：合併 main 後由現有 Render 自動更新。不新增資料表、付費服務或 API。回滾本次提交恢復前版查詢行為，沒有交易資料異動。
