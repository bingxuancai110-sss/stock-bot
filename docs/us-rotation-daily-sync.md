# 美股每日收盤更新修復

2026-11-11 正式畫面仍停在 11/6。正式日誌確認：原先只在 07:00 warmup 更新美股輪動，11/11 07:00 時 RSS 271MiB 加上預留 280MiB 超過容許值，工作未獲准執行；其他 warmup 時段又略過美股日線，導致持續沿用舊快照。不得以取消網站記憶體保護作為解法。

改為 GitHub Actions 於台灣時間週二至週六 06:35、07:05 目標排程執行（日程可能受 GitHub 排隊延後），可手動重跑。下載 18 組既有 Yahoo 日線在 GitHub 執行，Render 僅驗證約 380KB 的 CSV、計算既有指標並保存既有資料表，不啟動 58 檔台股研究或全市場掃描。原晨間 warmup 不再重複下載這批歷史；台股研究原有下午更新保持獨立。

機器更新使用限縮 repo/main/指定 workflow/audience 的 GitHub OIDC，無新長期金鑰。月線 workflow 憑證不能跨用此入口，使用者登入和 LINE 不變。資料庫使用獨立、短生命週期的工作連線，沿用原 helper。

資料驗證沿用正式 CSV 檢查：有限值、正價格、OHLC 合理、重複與未來日期阻擋、產業代理至少 61 個同日期交易日、ETF 還原價不可缺。另要求 VIX、HYG、IEF、S&P 500 與 SPY 最近已收盤日期一致。美國當日 17:00 前不使用其當日日線。較舊批次不能覆蓋最新快照；相同資料日沿用既有 upsert，逾時可安全重試。只有 commit 成功才回傳 snapshot_id／日期，HTTP 202 不算成功。

72 小時未成功更新的快照，在風險卡片標示「歷史資料」與更新逾時，不假裝是目前市場狀態；保留原數值與資料日期，週末／休市仍以實際資料日期解讀。來源為既有非官方 Yahoo 端點，非即時行情。美國 11/10 收盤通常在台灣 11/11 清晨取得，資料日仍應寫 11/10，不能改成自然日 11/11。

本機真實行情驗證：18 組皆取得，VIX 至 2026-11-10 為 19.459999（顯示 19.46），SPY／HYG／IEF／S&P 500 同日，CSV 379664 bytes。測試 51 項通過，包含截斷未收盤日線、缺資料拒絕、資料庫失敗不誤報成功、未授權與過大請求、月線／美股工作簽章隔離、舊資料標示與既有輪動計算回歸。

部署：合併 main 自動更新 Render，限定 push 會同時啟動一次真實行情補更新；需驗證部署 live 與 Actions 保存結果。沒有新資料表、Render 服務或付費 API。回滾前先停用該 GitHub workflow，回復程式；既有快照和歷史價格可保留，回滾不撤銷已保存資料。
