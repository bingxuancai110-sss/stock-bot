# Status-first short-term cards and price coverage

The initial list repeated action notes, technical checks, chip facts and long source explanations on every card. It also mixed watch-only, active and closed model states, making an old entry look actionable. Replace the collapsed list with explicit state groups and four state tabs (all / in model position / never entered / exited). Each tab filters the full stored qualified set, then returns at most six; its counts are calculated before truncation. Unconfirmed data is shown separately in all results.

State is derived from the latest confirmed entry/exit event. A provisional intraday entry does not put a stock in the confirmed position group; a provisional exit does not remove an existing confirmed position. Provisional actions remain explicit badges and current-session notices. These are strategy states, not the user's brokerage inventory.

Collapsed cards show name/code, current price/change, state/date, entry or observation level, stop and target, and one relevant per-share spread. Closed positions do not show new observation levels as if still held. K-line, detailed current rationale, checks and institution references are available after expansion. Timeline dates/actions and short reasons remain visible; numerical detail expands separately. Refresh/coverage diagnostics and rules move to disclosure panels. No full-page reload is added. A filter pressed while a request is pending is queued instead of discarded.

No nominal share-price ceiling/floor or institution net-buy lots participate in universe selection, technical ranking, entry or final ordering. Preserve existing relative-volume and overheat/risk rules. Audit quote/technical/deep/qualified counts in four nominal-price bands as diagnostics; nominal-price bands also interleave capped detailed research so a whole high-price band is not silently erased. Entry eligibility and final technical ordering do not change. Show a bounded sample of high-price initial screening reasons. These are counts from actual requests, never fabricated coverage. A selection-version bump rebuilds older snapshots for diagnostics.

API adds optional `position=held|waiting|closed|unknown`, keeping authentication and existing sector filtering. Payload meta adds position_counts; stored scope adds price_coverage and high_price_examples. No schema change, new vendor, account mutation or LINE sends.

Validation: confirm price-scale invariance (20x the same OHLC prices), high-price tiny-volume entry without institutional evidence, preview/confirmed-state separation, filtering beyond the six default cards, coverage arithmetic, readable light/dark tabs, compact cards, existing chart/history/polling and full UI regressions. Production checks must inspect actual high-price counts/reasons and the redesigned state filters. Rollback is a code revert and normal main auto-deploy; stored history remains retained.

Production audit found 37 quotes in the 500–999 band and 35 in the 1000+ band; three passed preliminary technical rules but none reached the original capped detailed list. Selection version 7 interleaves setup/sector/price-band research buckets, preserving the 80-symbol cap and existing active symbols. A regression reproduces 100 lower-price candidates crowding out three high-price candidates and verifies all three receive research without declaring an entry.
