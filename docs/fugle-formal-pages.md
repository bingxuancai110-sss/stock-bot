# 富果接入正式今日／持股頁

原本富果只在個人測試頁運作，正式頁仍由 MIS／Yahoo 更新。現在保留既有 owner 設定（FUGLE_TEST_USER_ID 或 FUGLE_TEST_USER_EMAIL），同一個瀏覽器行情引擎可在正式今日、持股與富果頁沿用。

## 使用

1. 重新整理網站，在今日或持股頁展開「富果行情」。
2. 輸入原本的富果行情 API Key，按「啟用富果行情」。預設追蹤 BOT 持股。
3. 啟用後面板收合，顯示已更新檔數；在網站內切換今日／持股沿用同一條連線。
4. 停止、關閉或重新整理會清除金鑰。切到背景會暫停傳輸，回前景重新確認持股並恢復。金鑰只在分頁記憶體，不進 localStorage、sessionStorage、Cookie、BOT API 或資料庫；原本測試頁沒有保存金鑰，所以新版第一次啟用仍須重新輸入。

## 資料與額度

- 共用既有免費配置：最多 5 個成交串流訂閱，其他持股定時查詢；REST 本分頁上限 40 次／分鐘，保留免費方案 60 次額度的餘裕。基準資料先逐檔初始化，失敗不阻塞其他股票。
- 各股以日內報價 API 的 previousClose／referencePrice 建立每日基準。遇除權息使用今日參考價配對正式成交；不使用含試撮的 lastPrice／changePercent 冒充成交。
- 行情到達後傳送價格、每日基準、成交與觀測時間至 owner 私人計算端點，不傳 API Key。既有持股、手續費及日內交易切段計算共用，不另造報酬模型。
- 更新今日貢獻、組合報酬與持股價格／今日損益／市值／持有報酬／估算費用／配置權重。缺股時不顯示部分加總為完整報酬。TAIEX 仍採原有官方指數來源，歷史走勢與 LINE Bot 資料流程不變。
- 啟用期間正式頁原 MIS／Yahoo 輪詢停止套用；較晚完成的舊來源回應也不覆蓋富果資料。停止後一般行情流程可恢復，各來源仍明確標示。
- POST 僅允許原 owner、綁使用者 CSRF、目前持股及有限輸入大小；拒絕跨日、未來、失效觀測、非法價格、試撮與零股。收盤後須有富果收盤旗標。計算結果只回本人瀏覽器，不寫共用行情／績效快照，避免當成其他人的官方來源。
- 429 遵守至少 60 秒冷卻；認證失敗會停止並清除金鑰。沿用瀏覽器連線鎖與最多 5 個訂閱的確認流程。

## 驗證

- 82 項 Python 測試通過，包含 owner／CSRF、價格與日期、參考基準、試撮／零股、收盤、完整／部分組合、既有費用與買賣切段。
- Chromium／WebKit 各 14 項正式頁整合檢查通過：真實 renderer 與計算函式、十檔初始化、5 個訂閱、跨頁單一連線、來源與金鑰去向、背景恢復、429 冷卻，以及 360／390／430／1280 寬度，無 JS 錯誤。
- 既有全站互動回歸每個引擎 102 項通過。WebKit 選取色檢查等待短暫按壓動畫結束後讀取穩定狀態。
- 富果網路傳輸使用模擬資料驗證；沒有取得使用者金鑰，因此不宣稱已完成本人帳號的真實富果連線或 iPhone 實機驗收。
